# Narrative map data

This directory is the editable source for prose-linked historical map scenes. The PMTiles archive, presets, sprites, and static WebP fallbacks are generated publication assets and should not be edited by hand.

Chapter 1 uses three small evidence tables and one scene catalog:

- `ch01-features.csv`: sites, landscapes, gateways, production places, burials, and political centers.
- `ch01-routes.csv`: movement, exchange, diffusion, written itineraries, and retrospective traditional routes.
- `ch01-regions.csv`: deliberately approximate concentrations, candidate fields, and regional centers.
- `ch01-scenes.json`: bounds, prose-facing alternative text, and the compact legend for each scene.

## Stable visual grammar

Color identifies the evidence family: Paleolithic blue-grey, Jomon umber, Yayoi ochre, continental written record indigo, retrospective tradition plum, and neutral context grey. Shape identifies the object: settlement circle, burial diamond, production hexagon, political square, and gateway ring. Size expresses importance to the current passage. Opacity expresses certainty. Solid, dashed, and dotted lines distinguish comparatively secure, inferred, and traditional routes.

Interpretive regions are not borders. Their low-opacity fill and dashed edge must remain subordinate to the sites and routes discussed by the prose. Yamatai must never be pinpointed; the Wa scene keeps secure northern stages distinct from disputed continuations.

## Publication sequence

1. Edit the CSV/JSON source data and audit it against the chapter prose and primary OCR.
2. Rebuild the atlas with `tools/build_web_atlas.py`.
3. Produce clean WebP scene fallbacks in `docs/Ancient Japan History/ch01/maps/scenes`.
4. Run `tools/history_reader.py refresh-maps --manifest config/ancient-japan-ch01.json` to replace only the map catalog and paragraph map references. This command intentionally preserves the approved prose, timelines, illustrations, and audio references.
5. Preview with `tools/serve_reader.py`, exercise every scene, test the map key and popups, and verify iPad portrait and landscape layouts.

Audio is outside this map pipeline and is never generated by these steps.
