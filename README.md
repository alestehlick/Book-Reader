# Book Reader deployment repository

This repository publishes static reader folders from `docs/`.

The Ancient Japan project is authored and built outside this repository at:

`H:\Ancient Japan History`

Only the completed static folder below is deployed here:

`docs\Ancient Japan History`

Do not edit Ancient Japan prose, timelines, illustrations, maps, audio, schemas, or build scripts in this repository. Rebuild them from the H: project and replace the static deployment folder only after `READY_TO_COPY.txt` has been produced.

Other historical readers under `docs/` retain their own existing arrangements.
